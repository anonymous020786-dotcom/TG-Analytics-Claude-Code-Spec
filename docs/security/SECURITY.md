# Security Baseline

Use OWASP ASVS as verification baseline.

Threats: account takeover, SQL injection, XSS, CSRF, SSRF, IDOR, privilege escalation, API abuse, brute force, queue poisoning, webhook spoofing, payment fraud, secret leakage and dependency compromise.

Controls: validation, parameterized queries, secure cookies, authorization, CSRF strategy, CSP/HSTS/security headers, rate limiting, audit logs, secret management and dependency scanning.
